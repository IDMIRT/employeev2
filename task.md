Кейс

Крупная компания-заказчик поручила разработать веб-приложение для отображения и управления данными о сотрудниках с пятиуровневой иерархией подчинения. Готовое решение позволит HR-отделу быстро фильтровать сотрудников по ФИО, сортировать по зарплате или дате найма и корректировать подчинение без риска нарушения целостности данных.

Задача:

Разработать веб-приложение на основе Flask и SQLAlchemy, отображающее информацию о сотрудниках из базы данных и предоставляющее функционал поиска и обновления данных.

Данные о сотрудниках:
ФИО
Должность
Дата приема на работу
Размер заработной платы
У каждого сотрудника есть 1 начальник.
База данных должна содержать не менее 50 000 сотрудников и 5 уровней иерархий по должности (например, CEO → Manager → Team Lead → Senior Developer → Developer).
Технические требования:

Python 3.7+

Flask

Flask-SQLAlchemy

MySQL 5.6+ / PostgreSQL 10+

Git (для управления версиями кода)

Выберите подходящую СУБД (MySQL или PostgreSQL) и спроектируйте схему базы данных, которая будет эффективна для хранения и обработки данных о 50 000+ сотрудниках. 
Для генерации данных сотрудников рекомендуем использовать библиотеку Mimesis, позволяющую генерировать фиктивные и в то же время валидные данные. 
Создайте модели Flask-SQLAlchemy, отображающие структуру таблиц из базы данных.  Модели должны включать все необходимые поля и связи между таблицами (например, связь «начальник-подчиненный»).  Связь между моделями реализуется через  внешние ключи.  Требуется четкое определение типов данных для каждого поля.
Разработайте страницу, отображающую список всех сотрудников.  Каждый сотрудник должен быть представлен с полной информацией (ФИО, должность, дата приема на работу, зарплата, начальник).  
Реализуйте сортировку по любому полю, используя параметры GET-запроса.
Реализуйте функционал поиска сотрудников по ФИО (полное или частичное совпадение).  Результаты поиска должны отображаться на той же странице.
Реализуйте возможность изменения начальника сотрудника путем прямого обновления записи в базе данных.
Убедитесь, что данные отображаются корректно на странице и что сортировка работает правильно.
Приложение должно корректно обрабатывать ошибки (например, ошибки базы данных, некорректные запросы).  Пользователь должен получать понятные сообщения об ошибках.
При выполнении задания вы можете дополнительно использовать любые сторонние Python библиотеки, без всяких ограничений. Они должны быть добавлены в проект через pip/bower/npm/yarn, если библиотека поддерживает такой способ установки. 
Выполненное задание должно быть отправлено на проверку в виде ссылки на GitHub репозиторий.
Сроки реализации задачи — 1 неделя (13-14 часов чистого времени).
Самопроверка

Для того чтобы ничего не упустить в процессе выполнения задания, еще раз проверьте себя по чек-листу:

Создана база данных с данными о сотрудниках (ФИО, должность, дата приема, зарплата).
Установлена иерархия: каждый сотрудник имеет одного начальника.
База содержит минимум 50 000 записей и 5 уровней иерархии.
Модели Flask-SQLAlchemy созданы, типы данных верны, связи (включая «начальник-подчиненный») реализованы. Целостность ссылок проверена.
Список сотрудников отображается, информация полная и корректная.
Сортировка по GET-параметрам работает корректно для всех полей. Поиск по ФИО (полное/частичное совпадение) работает корректно.
Изменение начальника работает, исключения обработаны (циклические ссылки, несуществующие начальники).
Ошибки базы данных и другие ошибки корректно обработаны и отображаются пользователю.
Репозиторий создан, код структурирован, README файл написан.
Проведено ручное тестирование всех функций.
