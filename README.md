🏢 Управление сотрудниками

# Веб-приложение для управления структурой компании, реализованное на Flask + SQLite (авторизация) + PostgreSQL (рабочие данные).

🚀 Особенности архитектуры
Динамическая БД: Основная база данных (PostgreSQL) запускается в Docker-контейнере только после успешной авторизации пользователя.
Разделение баз:
Пользователи хранятся в локальном файле SQLite (users.db) — это обеспечивает быстрый вход без запуска тяжелых сервисов.
Рабочие данные сотрудников находятся в PostgreSQL внутри контейнера.
Гибкая сортировка: Реализована сложная логика сортировки по полям связанной таблицы (отделы), включая работу со строковыми представлениями полей из связанных таблиц.
Управление ролями: Возможность назначать «Руководителя отдела» прямо из интерфейса редактирования сотрудника.

# Требования к системе

Для корректной работы приложения необходимо:

Установленный Python (рекомендуется версия 3.9+).
Установленный Docker Desktop. Сервер не запустится без работающего Docker Engine.
Установленные зависимости (см. файл requirements.txt):
pip install -r requirements.txt

# Запуск приложения
## Шаг 1. Генерация тестовых данных

Если вы запускаете проект впервые, создайте структуру базы данных и наполните её данными.

Базовый набор (5000 сотрудников, 10 отделов)
python test_data_add.py 

Или укажите свои значения через аргументы
python test_data_add.py -e 50000 -d 25

Важно: При первом запуске скрипт создаст папку data/ рядом с проектом для хранения тома PostgreSQL.

## Шаг 2. Запуск сервера

Запустите основной файл приложения:

flask --app run.py run

Приложение будет доступно по адресу http://127.0.0.1:5000



# 🖥 Интерфейс пользователя
Авторизация

На главной странице выберите существующего пользователя из выпадающего списка и введите пароль.

Данные пользователей берутся из файла users.db (SQLite).
Пароли должны храниться в открытом виде или быть захешированы (в текущей реализации используется прямое сравнение).
Работа со списком сотрудников

После входа открывается таблица сотрудников.

Сортировка: Нажмите на заголовок колонки («ФИО», «Зарплата») для смены направления сортировки. Приложение поддерживает сложную сортировку по связанным данным (например, поиск начальника отдела).
Пагинация: Список разбит на страницы по 50 записей для быстрой загрузки.
Редактирование структуры
Перейдите во вкладку «Подразделения».
Нажмите кнопку «Редактировать» напротив нужного отдела.
В открывшемся окне можно сменить руководителя подразделения.
При смене руководителя у текущего босса автоматически снимается флаг boss_department=True, чтобы избежать дублирования начальников.

# 🐳 Механика работы с базой данных

Проект использует гибридный подход к работе с SQLAlchemy:

Авторизация: Работает напрямую с SQLite до момента нажатия кнопки «Войти».
Основная БД: После успешного входа вызывается функция start_docker(). Только после того, как контейнер Postgres ответит статусом healthy, происходит инициализация движка ORM для рабочей базы.
Связи: Используется связь "Многие-к-одному" между сотрудником и отделом.
Структура моделей (модели подразумеваются исходя из кода)
Модель	Поля
Employee	id, name, employee_position, salary, date_employment, department_id (FK), boss_department (bool)
Department	id, name_department, parent_id (Self-referential FK для иерархии)

# 🐞 Возможные проблемы и решения
|Проблема	|Решение|
|---------|-------|
| Ошибка No module named 'sqlalchemy'| Выполните pip install -r requirements.txt или проверьте активацию виртуального окружения.|
| Кнопка "Выйти" не меняет состояние	| Очистите куки браузера (Ctrl+Shift+R) или добавьте SESSION_PERMANENT = False в настройки Flask.|
| Медленная загрузка при старте |	 Это нормально. Скрипт ждет готовности контейнера PostgreSQL (до 60 секунд). Не закрывайте страницу.|
| Не работает смена начальника	| Убедитесь, что перед сменой флага boss_department у старого босса выполняется сброс этого флага для всех остальных сотрудников его отдела.|
