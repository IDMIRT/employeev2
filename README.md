Программа работы с сотрудниками в базе.
Возможности программы:
Работа с авторизованными пользователями, пользователей необходимо добавить в таблицу users в базе SQLite users.db.
Отображение списка сотрудников ФИО,Должность,Дата приема, Заработная плата по любому из полей возможн сортировка
Возможность сменить отдел для сотрудника при смене отдела у сотрудника меняется рукводитель.
Возможность сменить начальника отдела
Поиск по ФИО или частичному совпадению
Необходимые приложения для работы:
Установленный python и Docker(Важно!!! для работы docker должен быть запущен), для корректной работы необходимо установить пакеты из requirements.txt "pip install -r requirements.txt"
Перед началом работы запустите файл test_data_add.py "python test_data_add.py" по умолчанию заполняется 5000 сотрудников и 25 отделов если нужно больше введите команду 
"python test_data_add -e 50000 -d 25" по данной команде создается 50000 сотрудников и 25 отделов ключ -e сотрудники -d отделы
Запуск программы для проверки, в папке программы "flask --app run.py" или через вебсервер
